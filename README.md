# Python-Indian-E-Commerce-Sales-Customer-Analytics
Python EDA on a 9-table Indian e-commerce dataset (659,318 total rows) covering **Sales &amp; Revenue, Customer Analytics &amp; Retention, Logistics &amp; Returns, and Marketing ROI**.

## 📊 What's Inside

- Monthly revenue & order volume trend
- Revenue and profit margin by product category
- Order status funnel
- Loyalty tier and RFM customer segmentation
- On-time delivery rate by shipping method
- Return rate by product category
- Marketing channel ROI comparison

All charts use a consistent navy (`#1F3864`) / amber (`#E8A33D`) brand palette.

## 🗂️ Dataset

| Table | Rows | Description |
|---|---|---|
| customers | 25,000 | Customer profile, signup, spend, loyalty tier |
| products | 550 | Product catalog, pricing, ratings |
| marketing_campaigns | 151 | Campaign spend, conversions, ROI |
| orders | 100,000 | Order-level transactions |
| order_items | 254,331 | Line-item detail per order |
| payments | 100,000 | Payment method, status, refunds |
| returns | 12,075 | Return reason, refund amount, status |
| shipments | 89,681 | Dispatch, delivery, delay tracking |
| customer_reviews | 77,530 | Ratings and sentiment |

## 🛠️ Tech Stack

- Python 3 · pandas · numpy · matplotlib · seaborn

## 🔑 Key Findings

- Revenue growth is largely **order-volume driven**, with a fairly stable average order value across months.
- RFM segmentation surfaces a sizeable **At-Risk / Lost** customer base — a clear retention target.
- On-time delivery rate varies meaningfully by **shipping method**, which correlates with return rates.
- Marketing **channel ROI is uneven** — reallocating spend toward the top-ROI channels is the clearest lever.
